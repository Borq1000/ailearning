## Курс 2 «Как модель учится» (после M3 курса 1, ориентир — после M5)

Закрывает сознательный пробел курса 1 (спецификация §2: backprop не входит). Эскиз:
производная с нуля → градиентный спуск на 3D-ландшафте ошибки (глубина несёт смысл — правило §5.4) → функция потерь и cross-entropy (связь с softmax из 1.6) → backprop на маленьком графе вычислений → **финальный проект: ученик обучает W_Q, W_K, W_V для загадки «он» градиентным спуском** и сравнивает с подобранными вручную весами из `content/attention/toy-model.ts`.

Техническая предпосылка выполнена в M1b: прогресс под курсом (`scopeId`), глоссарий с `courseId`, главная по `listCourses()`. Для курса 2 понадобится: второй манифест `content/learning/course.ts`, регистрация в `lib/course/registry.ts`, свои упражнения и, вероятно, `lib/math/autograd.ts` (скалярный автограф для демонстрации backprop).

## Дальше (порядок обсуждается после курса 2)

- «От статьи 2017 к LLM 2026»: формат «что было → что поменяли → почему» (decoder-only, BPE, scaling laws, RoPE, RMSNorm, SwiGLU, KV-cache/GQA, MoE, FlashAttention, RLHF, reasoning).
- «Заглянуть внутрь» (интерпретируемость): паттерны голов, induction heads, residual stream, суперпозиция — нужны данные реальной модели.
- «LLM в руках программиста»: эмбеддинги и поиск (косинус из 1.3), RAG, tool use, evals — ограничение статики: заранее посчитанные данные или ключ API ученика.
- «Внимание за пределами текста»: ViT, CLIP, интуиция диффузии.
- Формат «Читальный зал»: одна знаковая статья за урок по образцу 7.3.

## Сквозные идеи базы знаний

- Граф понятий: связи «опирается на» между терминами глоссария; подсказка «что нужно знать перед уроком»; 3D-карта освоенных понятий на главной (`WordCloud3D` уже есть).
- Общая колода повторения на все курсы (уже так устроена: `/review` собирает карточки всех курсов).
- Данные реальных моделей: офлайн Python-скрипт → JSON в `content/<course>/data/`, статическая сборка не меняется.
